11.3 Functions of the Distributed Security System

You can create a distributed system within an Axxon Domain on Axxon One.

Axxon Domain – a selected group of computers on which the server configuration of the Axxon One software package is installed. 
Linking the servers in a group makes it possible to set up interaction between them, thus organizing a distributed system.

Servers are interoperable only if they belong to the same Axxon domain. At the same time, each Server of the domain operates 
independently and has its own DB.

If activation has not been completed, Axxon One works in demo mode.

The system will operate in demo mode from 8:00 AM to 6:00 PM. There are limitations to functionality (see Axxon One license 
types(see page 108)).

The different types of demo modes are presented in table.

| Type of demo mode | Conditions | Axxon One operation |
| --- | --- | --- |
| Active | Axxon One can be started between the hours of 8:00 AM and 6:00 PM | Using Axxon One in demo mode |
| Inactive | Axxon One started outside the hours of 8:00 AM and 6:00 PM | The Axxon One server is not available, only the system configuration can be viewed |

If a Client is connected to an Axxon Domain in which there is at least one Server running in demo mode, an appropriate message 
is displayed, along with a list of Servers in the Axxon Domain and their types of licenses.

The notification is displayed after successful authorization.


Note

If an Axxon Domain includes at least one Server running in active demo mode, you will be given the option to continue working 
(2) or start the activation utility (1).
